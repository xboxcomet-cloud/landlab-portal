LH 공공데이터 API 설명 ↗

공공데이터포털 API는 활용신청과 인증키가 필요합니다. 현재 LANDLAB의 공고 목록은 확인된 LH 공식 원문과 일부 공고 재제공 사례를 표시합니다. 자동 API 수집은 인증키 설정 후 작동합니다.
