배포 방법
1. 이 ZIP 파일을 맥북에 내려받아 압축을 해제합니다.
2. 압축을 푼 폴더 안의 파일 전체를 선택합니다. ZIP 파일만 올리지 마세요.
3. https://github.com/xboxcomet-cloud/landlab-portal/upload/main 에서 선택한 파일을 업로드합니다.
4. index.html 등 기존 파일을 교체하는 메시지가 표시되면 확인하고 Commit changes를 클릭합니다.
5. https://landlab.kr 을 새로고침합니다. 변경이 보이지 않으면 강력 새로고침/캐시 삭제 후 재확인합니다.

주의: 기존 GitHub의 naver*.html 인증 파일은 삭제하지 마세요.
GitHub Pages가 아니라 Cloudflare Pages의 현재 설정이 연결되어 있을 때만 이 업로드로 공개 홈페이지가 업데이트됩니다.
