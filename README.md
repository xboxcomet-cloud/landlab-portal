# LANDLAB 홈페이지 — 2026.11.09 업데이트

## 이번 변경
1. 왼쪽 위 느티나무 로고를 SVG 파란색 계열로 통일했습니다.
2. 발주·입찰 페이지에서 실제 수록 공고 목록을 페이지당 **8건**씩 보여줍니다. 조건 검색, 지구 선택, 정렬, 단계 선택 시 페이지가 1로 초기화됩니다.
3. 6개 지구 × 8개 발주 업무유형의 수록 여부를 표시하는 비교표를 수정했습니다. 기존의 '번호가 가장 높은 단계=현재 사업 단계' 방식은 잘못된 추론이므로 제거했습니다.
4. 홈 화면에도 동일 자료의 축약 비교표를 추가했습니다.
5. 근거로 사용한 29개 수록 공고의 건수와 마지막 공고일을 `district-stage-coverage.csv`로 추출했습니다.

## 해석상 주의
- **8단계는 부지조성에 연관된 발주 업무 분류**이며 법정 사업 진행률이나 공사 진척률을 뜻하지 않습니다.
- ●는 이 사이트가 수록한 공고가 있다는 뜻입니다. —는 해당 공고를 아직 수록하지 않았다는 뜻이며, 실제 사업 미진행이나 공고 부재의 증거는 아닙니다.
- 최근 수록 공고 업무단계는 '현재 사업 단계'와 다릅니다. 예컨대 공사 중 성과도/GIS 용역이 발주될 수도 있습니다.
- 이 사이트는 공공데이터포털 API 인증키가 없는 상태로, 자동 갱신은 아직 활성화되지 않았습니다.
- 공고 사례에는 LH 공식 원문 및 일부 재제공 자료가 섞여 있으며, 공식 원문 재검증이 필요할 수 있습니다.

## 배포 안내 (GitHub 웹 업로드)
1. ZIP을 다운로드한 뒤 압축 해제합니다.
2. **압축을 푼 폴더 안에서** 파일을 전체 선택합니다. 다운로드 폴더 전체를 선택하지 않습니다.
3. GitHub `xboxcomet-cloud/landlab-portal` 저장소 `main` > `+` > `Upload files`에서 파일을 업로드하고 `Commit changes` 합니다.
4. ZIP 자체는 업로드하지 마세요. 기존 네이버 검색엔진 인증 HTML은 삭제하지 마세요.
5. `landlab.kr`에서 새로고침하여 반영을 확인합니다.

※ 이 ZIP에는 폴더 중첩 없이 웹사이트 파일이 **ZIP 최상위에 직접 들어 있습니다**.
