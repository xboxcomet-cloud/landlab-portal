# LANDLAB — 2026-11-11 연구형 데이터 포털 개선본

이 파일을 `landlab.kr` GitHub 저장소 `xboxcomet-cloud/landlab-portal`의 루트에 올리면 정적 홈페이지가 교체됩니다. 기존 네이버 인증 HTML 파일은 삭제하지 마세요.

## 이번 수정
- 홈: 수록 데이터 범위·데이터 갱신 상태·구축 로드맵 표시
- 3기 신도시: 6개 지구 개략 위치 지도(Leaflet + OpenStreetMap), 공식 토지이용계획 CSV 업로드 시 비율 비교 계산
- 연구자료실: Excel, CSV, JSON, BibTeX, RIS 제공
- 연구 도구: 엑셀 탭·줄바꿈 붙여넣기 개선, 브라우저 내 입력 저장·복원, JSON 내보내기 및 인쇄/PDF
- 발주·입찰: 29건 기존 연구용 사례 검색·페이지 조회·8단계 수록표 유지, 예정가격·낙찰금액·계약업체는 검증 여부 명시
- 보상·재결: 점검표 저장·인쇄/PDF·CSV 내보내기와 판례 공식 조회 경로
- 분양·청약: 6개 지구별 상태표(확인되지 않은 날짜는 '공식 확인 전')
- 공식 출처: 공공데이터 API별 데이터셋·필드·유의점 추가
- 모바일: 데이터 표 가로 스와이프 안내와 첫 열·헤더 고정, 앵커 부드러운 이동
- 로고: 파란색 PNG/SVG 일치. 모든 웹페이지 파비콘에 버전 파라미터 적용
- '문의하기' 메뉴나 폼 없음

## 검증 주의
- **실시간 데이터 수집은 인증키 없이 활성화되지 않습니다.** 이 패키지에는 기존 선별 사례와 API 설정 준비 파일만 있습니다.
- 조달청 입찰공고정보서비스는 2026-11-10부터 조회기간 상한이 7일입니다.
- LH 자체 입찰 API 연결과 낙찰·계약 정보 API 매핑은 추가 확인·개발이 필요합니다.
- GIS에 표시한 지점은 개략 위치이며 **법정 사업지구 경계가 아닙니다.** 실제 구역 경계와 광역교통망 GIS는 VWorld 키·공식 도형이 있어야 추가할 수 있습니다.
- 토지이용계획 비율은 실제 공식 자료를 입력하기 전까지 공란입니다. 자료를 임의 생성하지 않았습니다.
- 인용은 LANDLAB 수록본에 대한 메타데이터이며 법적 고시·공고의 원문 인용을 대체하지 않습니다.
- 자동수집 관련 `.github`/`scripts`는 별도 **API자동수집_선택설정용.zip**에 보관합니다. 정적 웹페이지 배포와 분리하여 설정할 수 있습니다.

## 업로드 방법
1. ZIP 다운로드 후 압축 풀기
2. 내부의 파일들을 GitHub 저장소 `main`의 **최상위**에 업로드 (ZIP 파일 자체를 올리면 안 됨)
3. `Commit changes` 클릭
4. Cloudflare Pages 배포 완료 후 `https://landlab.kr`에서 화면 확인
5. 기능 점검: `/towns.html`, `/tools.html`, `/compensation.html`, `/procurement.html`, `/research.html`
6. 브라우저에 이전 아이콘이 보이면 Ctrl+Shift+R, 캐시 확인
